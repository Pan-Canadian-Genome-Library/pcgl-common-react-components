# Using the tokens

Every token comes from one Token Source in `@repo/ui`. Two outputs are generated from it: a Tailwind theme for Tailwind Portals and a theme object for antd Portals. 
Pick the one for your Portal, then your Portal's Theme. Both kinds of Portal also load the fonts; see [Typography](?path=/docs/guidelines-typography--docs).


> 🫣 Also you can copy and paste the values in your own implementation for a quick adoption instead of installing the whole library, configuring typescript or ant theme.


## Tailwind Portals

Install `@repo/ui`, then import Tailwind and your Theme's stylesheet. That's the whole setup; you don't need any shared component.

## antd Portals

Pass your Theme's object to `ConfigProvider`, and import your Theme's focus stylesheet:

<Source language="tsx" code={antdSetup('research')} />

> Important: 

- The object sets every shade explicitly, so an antd upgrade can't change PCGL colours. It uses only token names that exist in antd 5 and antd 6.
- It imports nothing from antd. Your Portal's compiler checks it against antd's `ThemeConfig` when you pass it to `ConfigProvider`, so a wrong token name fails your build.
- The focus stylesheet sets the focus ring's colour and offset on `:focus-visible`, which antd tokens can't do. The object sets its width (`lineWidthFocus: 2`). antd components that draw focus another way, such as with a box shadow, are corrected in the Portal.
- Add the heading rule from [Typography](?path=/docs/guidelines-typography--docs) so headings use Jost.
